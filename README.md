# save the date

A tiny pixel-art invitation. Three screens: the question, the date range picker,
and the confirmation. Saying no only makes the YES button bigger.

When someone picks a range and hits SAVE, the dates are emailed to you.

## Running it locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Getting the email

Email goes out through [Resend](https://resend.com), called over plain HTTP — no
SDK, no extra dependency.

1. In Resend, create an API key (**API Keys → Create**). A separate key per
   project is worth it: you can revoke this one without touching anything else.
2. Copy `.env.example` to `.env.local` and fill in:

   ```
   RESEND_API_KEY=re_...
   NOTIFY_EMAIL=you@example.com
   ```

`NOTIFY_EMAIL` is where the notification lands. Without a verified domain Resend
only delivers to the address that owns the account — which is fine here, since
the mail goes to you. If you already have a domain verified on the account, you
can send from it instead by setting `NOTIFY_FROM`.

With the variables missing the app still works; it just records the pick without
mailing anyone.

## Deploying to Vercel

Import the repo, then add `RESEND_API_KEY` and `NOTIFY_EMAIL` under
**Settings → Environment Variables** and redeploy — env vars are only picked up
by builds that run after they are set.

**Test the deployed link yourself before sending it to anyone.** Pick a range,
hit SAVE, and check that the mail arrives. If the key is missing or wrong, SAVE
shows an error instead of silently losing the answer.

Vercel's filesystem is read-only, so on Vercel the email is the only record. Run
locally and every pick is also appended to `data/picks.json`.

## API

`POST /api/pick` with `{"from":"YYYY-MM-DD","to":"YYYY-MM-DD"}` — validates the
range, records it, emails it. Responds `{ saved, stored, notified }`.

`GET /api/pick` returns the most recent pick and a count from `data/picks.json`
(local only — always empty on Vercel).

## Assets

`public/heart-*.png` are 16×16 pixel-art sprites generated by hand, used for the
drifting hearts, the cursor trail, and the flood after YES. The backgrounds are
`bg-sky.png` (question), `bg-london.png` (date picker) and `bg-packing.png`
(confirmation).
